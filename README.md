

# 📅 Smart Study Planner

A **web-based study planner** built with **HTML, CSS, and JavaScript** to help students organize study schedules, manage academic tasks, and boost productivity. The planner allows users to add, complete, and delete tasks for each day of the week, with tasks stored locally in the browser for persistent usage.

---

## 🚀 Features

* 📌 **Day-wise Planner** – Separate task lists for each day of the week (Mon–Sun).
* 📝 **Task Management** – Add tasks with title and notes.
* ✅ **Mark as Complete/Undo** – Toggle tasks as completed or undo them.
* ❌ **Delete Tasks** – Remove tasks when no longer needed.
* 💾 **Local Storage** – Tasks are saved in the browser and persist after page reload.
* 🎨 **Dark Theme UI** – Modern design with glowing effects for better focus.

---

## 🧩 Tech Stack

* **HTML5** – Structure of the planner.
* **CSS3** – Dark theme, animations, and responsive layout.
* **JavaScript (ES6)** – Task handling, local storage, and dynamic UI rendering.

## ⚙️ How It Works (Algorithm Overview)

1. Initialize app → Set default day & load tasks from localStorage.
2. User adds a new task (title + notes + selected day).
3. Tasks are stored under the selected day in localStorage.
4. Render tasks dynamically into task cards.
5. User can **mark complete/undo** or **delete** tasks.
6. UI updates instantly after every change.
